# swarmalator-nonresonant-forcing

**Project home:**

Codes for numerical simulations in the work:

**“Dynamics of 1D swarmalators in the presence of non-resonant forcing.”**

---

## Description

This repository contains simulation codes and notebooks for studying
collective dynamics of one-dimensional swarmalators under non-resonant
external forcing, including synchronized, pinned, and split states.

---

## Files

- `Swarmalators_states.ipynb`  
  Jupyter notebook for visualizing and analyzing emergent swarmalator states.

---

## Requirements

- Python / Julia (depending on the notebook setup)
- Standard scientific libraries (NumPy, Matplotlib, etc.)
